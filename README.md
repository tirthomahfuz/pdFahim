# pdFahim 📄✨

**pdFahim** is a clean, modern, browser-based PDF toolkit designed for students, freelancers, job seekers, and office workers. It provides essential PDF utilities grouped in a beautiful, simple, distraction-free interface.

Built with **Next.js**, **Tailwind CSS**, and **pdf-lib**, pdFahim is designed as a *local-first*, 100% privacy-respecting tool. All document processing happens entirely inside your browser—no files are ever uploaded or stored on an external server.

> **Note:** This is a portfolio-grade software project built to demonstrate modern UI development and client-side web capabilities. It is not currently deployed as a SaaS product.

---

## 🌟 Features

- 📑 **Merge PDF:** Combine multiple PDF documents into a single, cohesive file.
- ✂️ **Split PDF:** Extract specific pages or divide a large document into smaller parts.
- 🗜️ **Compress PDF:** Reduce the file size of your PDFs for easier sharing by removing metadata and unused objects.
- 🖼️ **Image to PDF:** Convert your JPG and PNG images perfectly formatted into PDF documents.
- 🔒 **100% Private:** Operates purely on the client-side. No backend, no APIs, no uploads.
- 💻 **Modern UI:** Built with Tailwind CSS, drawing inspiration from premium SaaS aesthetics.

## 🚀 Local Development Setup

To run pdFahim locally on your machine, follow these steps:

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### 1. Clone the repository
```bash
git clone https://github.com/shahriyar/pdFahim.git
cd pdFahim
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

### 4. Open in Browser
Visit `http://localhost:3000` to interact with pdFahim.
